# Bundled footage and attribution

These are two real 360° camera recordings, each offered with a license permitting redistribution and adaptations. The library lists each of the two recordings once. Format variants are selected from the player controls; Flat/360° is a view mode, not a duplicate catalog item. All sound is from the original location recordings; there is no synthetic audio replacement. Audio is normalized with FFmpeg loudnorm targeting -18 LUFS / -2 dBTP. Posters are extracted video frames.
