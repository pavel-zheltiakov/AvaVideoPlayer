AvaVideoPlayer/Playback

Use the browser backend

Browser decoding, real sound and a WebGL view for spherical video.

Register before startup

using AvaVideoPlayer.Browser;

await BrowserVideoBackend.RegisterAsync();
await AppBuilder.Configure<App>().StartBrowserAppAsync("out");

The browser portion of the single AvaVideoPlayer package includes browser/avavideo.js and a transitive MSBuild target that delivers the module to the browser application. The package-only browser sample demonstrates that setup.

Codec support belongs to the browser

The browser backend uses HTMLMediaElement for decode and audio. MP4 H.264/AAC and WebM VP9/Opus are included in the live demo. Browser support for MOV depends on its actual video/audio codecs. H.264/AAC MOV works in the tested Chrome environment; a MOV extension alone does not guarantee playback of HEVC, ProRes or other codecs.

Sound needs a gesture

Start playback from a click or tap. Browsers can block automatic audible playback. Keep Play visible and show any playback error to the user.

Local files

The player’s file picker creates a local object URL. Files stay in the browser; the demo does not upload them. Local-file URLs are released on source replacement and disposal.

Remote 360° video

WebGL requires permission to use remote media as a texture. Serve remote video with appropriate CORS headers. Same-origin media and local object URLs avoid cross-origin texture restrictions. HTTPS, redirects and authentication must still be checked against the hosting environment.

The screening-room demo

The live screening room lists two unique recordings with four selectable format variants and uses the same production browser module. It is a direct browser-module demo; it does not start the Avalonia WASM runtime. Its source is included in the public demo directory.
