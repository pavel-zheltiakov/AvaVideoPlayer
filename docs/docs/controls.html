AvaVideoPlayer/Playback

Control playback from code

Transport

await Player.PlayAsync();
await Player.PauseAsync();
await Player.SeekAsync(TimeSpan.FromSeconds(30));
await Player.SkipAsync(TimeSpan.FromSeconds(-5));
await Player.StopAsync();

Speed and sound

await Player.SetPlaybackSpeedAsync(1.25);
await Player.SetVolumeAsync(0.8, muted: false);

Speed is supported between 0.25× and 4×. Actual audio device availability and browser policies affect audible playback. Desktop audio is required by default when present; explicit silent/fallback policies are available through PlaybackOptions.

Read state

Player.Snapshot provides playback state, position, duration, media information, selected tracks and capabilities. Use the capabilities to determine whether a command is supported by the active backend.

Own the lifetime

Register the backend before control construction. Call the UI control on the Avalonia UI thread. Await commands and surface exceptions. Dispose the player when the host closes:

await Player.DisposeAsync();

Do not share a disposed player or reuse borrowed frame memory after releasing its lease. See the engine contracts in the API reference if implementing a backend or presenter.
