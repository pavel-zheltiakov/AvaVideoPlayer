AvaVideoPlayer/Start here

Play your first video

Register a backend before creating a VideoPlayer.

Requirements

  • .NET 10 SDK and an Avalonia 12.1.x application.
  • The single AvaVideoPlayer preview NuGet package; its framework and runtime assets are selected by NuGet.
  • A media file you can redistribute or use locally.

Install the preview

Download AvaVideoPlayer.0.1.0-preview.1.nupkg from the release page into a local packages folder. The preview is distributed through GitHub release assets; these instructions do not assume a nuget.org publication.

dotnet add package AvaVideoPlayer --version 0.1.0-preview.1 --source ./packages

The same package includes osx-arm64, win-x64, win-arm64, linux-x64 and linux-arm64 runtime assets. Choose your RID when publishing. Keep nuget.org configured for Avalonia and other third-party dependencies.

Register the desktop backend

using AvaVideoPlayer.FFmpeg.Avalonia;

// In the platform entry point, before creating controls:
FFmpegVideoBackend.Register();

Add the control

<video:VideoPlayer x:Name="Player" ShowControls="True" />

<!-- xmlns:video="clr-namespace:AvaVideoPlayer;assembly=AvaVideoPlayer" -->
await Player.OpenAsync(new Uri(Path.GetFullPath("movie.mp4")));
await Player.PlayAsync();

Call the control on the Avalonia UI thread. Dispose it when the containing view or window closes.

Run the package-only sample

dotnet restore demo/AvaVideoPlayer.Sample.Desktop --source ./packages --source https://api.nuget.org/v3/index.json
dotnet run --project demo/AvaVideoPlayer.Sample.Desktop -r osx-arm64 -- --ffmpeg movie.mp4
