AvaVideoPlayer

Video playback for Avalonia, from ordinary files to a view in every direction.

AvaVideoPlayer provides a video control, an owned FFmpeg playback engine for desktop platforms, and a browser backend that uses the browser’s media decoder and WebGL for 360° presentation.

A preview with explicit boundaries

The public preview uses .NET 10 and Avalonia 12.1.x. Package versions are pinned. Decoder execution and the browser demo have specific validation evidence; a package building for a platform does not establish audible output, GPU behavior, device recovery or clean-machine support on that platform.

See platform coverage before selecting a deployment target.
