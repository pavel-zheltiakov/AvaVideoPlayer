AvaVideoPlayer/Start here

One package, separate modules

Install one AvaVideoPlayer NuGet. The architecture stays modular inside it.

One install

dotnet add package AvaVideoPlayer --version 0.1.0-preview.2

The preview is published on NuGet.org and as a GitHub release asset. No other AvaVideoPlayer NuGet package is needed. Avalonia and its normal third-party dependencies remain external NuGet dependencies.

Framework and runtime selection

The desktop target embeds seven managed assemblies and five native RID profiles. The browser target embeds the control, engine and browser assemblies plus avavideo.js and an automatic MSBuild asset-delivery target. NuGet selects the appropriate target framework and runtime files.

Native source materials

Third-party licenses, original dependency archives, native bridge source and build recipes are included. Shared source archives are stored once. corresponding-sources/materialize.py reconstructs the exact source/build tree for a selected RID. These native rebuilding rights are retained separately from the owned managed implementation sources.

License

The owned software uses the same freeware model as Ava3DControl, including commercial application use. Demo sources may be reused. Third-party components and footage keep their own licenses.
