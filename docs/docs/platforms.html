Containers and codecs

Native local-file probes cover H.264 MP4 and H.264, HEVC and ProRes MOV. The live browser collection lists two unique recordings, with H.264/AAC MP4 and MOV plus VP9/Opus WebM format variants and original non-silent audio. Container support is not universal codec support.

Mobile

Android and iOS development/build work exists in the private development tree. Mobile runtime packages are not part of this public preview release. Do not infer device support from desktop or browser tests.

Network differences

The Linux ARM64 native input has newer HTTP timeout/cancellation validation than the other staged native profiles. This preview does not claim a uniform cross-platform network certification. Validate your transport, TLS and redirect needs on the actual target.
