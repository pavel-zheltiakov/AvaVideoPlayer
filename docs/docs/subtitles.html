AvaVideoPlayer/Playback

Subtitles, tracks and timing

Add a sidecar subtitle

await Player.AddSubtitleAsync(subtitleText, "English", "en");
await Player.SetSubtitleDelayAsync(TimeSpan.FromMilliseconds(250));

The desktop backend supports plain subtitle documents and ASS rendering through the owned FFmpeg/libass integration. Browser sidecars use WebVTT. Format availability differs between backends.

Select tracks

await Player.SelectAudioTrackAsync(audioTrackId);
await Player.SelectSubtitleTrackAsync(subtitleTrackId);

Read tracks and IDs from media information rather than assuming fixed track numbers. Browser audio-track selection is only available when the browser exposes that API; many browsers expose the default audio track only.

Inspect media

MediaInformation, MediaTrack, MediaChapter and MediaAttachment expose stream, chapter and attachment metadata. Desktop subtitle font loading is bounded. See the API reference for the exact public properties.
