AvaVideoPlayer/Reference

Resolve playback problems

Native library could not load

Install the single AvaVideoPlayer package, choose the correct process RID and verify that its selected native asset reaches the output. Do not copy a Windows x64 DLL into an ARM64 native process or mix unrelated development packages. Publish and run the package-only sample for the same RID.

Video plays without sound

Check mute and volume, verify the source has a non-silent audio track, and start browser playback with a user gesture. On desktop, inspect audio-output errors and the selected policy. A file containing an audio stream can still contain only silence.

A MOV opens but shows no video

MOV is a container. The browser may expose its audio while rejecting the video codec. Export H.264/AAC for wider browser compatibility or use the desktop FFmpeg backend for supported native codecs.

A 360° clip looks flat

Select 360°/equirectangular projection. In the screening-room demo, the catalog category selects a matching video and the explicit view selector shows the active projection. Drag within the video area; overlays and controls must not intercept orbit input. For remote media, also check CORS and WebGL availability.

Run the browser checks

Open the demo player with ?checks=1 to reveal diagnostic controls. The normal demo contains just the player and catalog. The report measures decoded browser audio and rendered pixels, not physical speaker output.
